# コマンドリファレンス

**構文は暫定です。** 固まるまで変わります（[仕様](spec.ja.md) 12章）。

```
yomicho build      <input.md> [-b <book.tsv>] [-o <out.md>]
yomicho update     <input.md> [-b <book.tsv>] [-d <ref.tsv>]... [--known <chars.txt>] [--full] [--force]
yomicho unresolved <input.md> [-b <book.tsv>]
yomicho merge      <input.md> [-b <book.tsv>] < filled.tsv
yomicho strip      <input.md> [-o <out.md>]
```

## 共通のオプション

| オプション | 意味 |
|---|---|
| `-b, --book <path>` | 原稿辞書。既定は原稿と同じ名前の `.tsv` |
| `-d, --dict <path>` | 参照辞書。近い順に複数指定できる |
| `-o, --out <path>` | 出力先。省略すると標準出力 |
| `--known <path>` | 既知文字リスト。この文字だけでできた語にはルビを振らない |
| `--full` | 通常は捨てる候補（カタカナ語・数値）も `*` として記録する |
| `--force` | `>` `!` `*` の行を捨ててから update する |
| `--all` | `unresolved` で全出現箇所を1行ずつ並べる |
| `-h, --help` | 使い方を表示 |

入力の原稿に既存のルビがあれば、どのコマンドでも先に取り除いてから処理します。

## build

原稿辞書だけを読んで変換します。**参照辞書も解析器も既知文字リストも読みません。**

```sh
yomicho build book.md -o out.md
```

原稿辞書1つで結果が決まるので、参照辞書が無い環境や他人の環境でも同じ出力になります。

## update

原稿を走査して、原稿辞書に足りない見出しを追加します。

```sh
yomicho update book.md -d ../global.tsv
```

```
book.tsv: 67 行 (+67) / 要対応 12
```

- 参照辞書から引けた見出しは `>` が付きます
- どこにも無い見出しは `?` が付き、3列目にスニペットが付きます。`?` を読みで置き換えれば確定です
- 原稿から消えた語は `?` が外れて空欄に戻ります。埋めなくてよい行が目で区別できます
- **型番・量・ファイル名は `*` が付きます。** 数字かドットを含む英数字トークン（`BMP280` `10cm` `0xFFE01F` `sketch.yaml`）が対象で、普通ルビを振らないものなので読みを聞きません。読ませたいときは `*` を消してください
- `--full` を付けると、カタカナ語と数値も `*` で記録します
- `--known` を渡すと、その文字だけでできた語に `!` が付きます
- **既存の行は書き換えません。** 一度決めた読みは update を何度実行しても変わりません

参照辞書の値を採り直したいときは、その行を消してから update してください。まとめて捨てるなら `--force` です。

## unresolved

要対応の行（`+` と空欄）を TSV で書き出します。**今回の原稿に出現した行だけ**を出すので、書き換えていない章の未解決行は混ざりません。

```sh
yomicho unresolved book.md
```

```
岬	?	途中の{岬}で引き返した。年寄りには
今日	?きょう|こんにち	{今日}は晴れ	{今日}中に終わる	{今日}的な問題
```

読みが割れる語には候補が `|` で並び、**出現箇所も全部（3つまで）** 付きます。要らない候補と `?` を消せば確定です。

`--all` を付けると1行ずつ、上限なしで並びます。

```
$ yomicho unresolved book.md --all
今日	?きょう|こんにち
	{今日}は晴れ
	{今日}中に終わる
	{今日}的な問題
```

整形していないので、そのまま AI に貼れます。3列目は出現箇所の抜粋で、対象を `{}` で囲んであります。

## merge

読みを取り込みます。標準入力から読みます。

```sh
yomicho merge book.md < filled.tsv
```

```
book.tsv: 取り込み 9 / 確定済みなので見送り 1 / 辞書に無い見出し 1
```

受け取り方は寛容です。列数は2でも3でもよく、記号は付いていてもいなくても構いません。そのうえで次を守ります。

- 取り込んだ読みには**必ず `+` が付きます**。外から来たものを無条件に確定させません
- **人の判断が入っている行は上書きしません。** 確定・`#`・`>` の行は見送ります
- 原稿辞書に無い見出しは取り込みません

`+` を消すのが承認です。エディタで1文字消すだけで、その読みは確定になります。`?` の行は `?` を読みで置き換えます。

## strip

原稿からルビを取り除きます。

```sh
yomicho strip book.md -o plain.md
```

## 典型的な流れ

```sh
yomicho update book.md -d ../global.tsv    # 足りない見出しを集める
yomicho unresolved book.md > ask.tsv       # 読みが要るものを書き出す
#                                            ask.tsv を AI に投げるか、自分で埋める
yomicho merge book.md < filled.tsv         # 取り込む（+ が付く）
#                                            book.tsv を開いて + を消す＝承認
yomicho build book.md -o out.md            # 変換する
```
