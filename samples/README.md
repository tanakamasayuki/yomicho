# サンプル

`sandbox/` に複製して試すための、傾向の違う日本語テキストです。

| ファイル | 傾向 | 試したいもの |
|---|---|---|
| `prose.md` | 一般的な説明文 | 送り仮名、複合語、リストや表の構造 |
| `novel.md` | 小説風 | 会話、当て字、熟字訓、同形異音語 |
| `school.md` | 学習用のやさしい文章 | 学年別フィルター、易しい漢字ばかりの文 |
| `news.md` | ニュース風 | 固有名詞、数値と単位、日付 |
| `global.tsv` | 参照辞書の例 | 階層解決、`#`、文脈指定、送り仮名の割り当て |
| `known-easy.txt` | 既知文字リストの例 | `!` によるフィルター |

`known-easy.txt` は `school.md` に出てくる漢字を並べただけの**例**で、学年別漢字配当表ではありません。
本物の配当表を同梱するかは未決です（[仕様](spec.ja.md) 12章）。

```sh
npm run sandbox              # そのまま流す
npm run sandbox -- --known   # 既知文字リストを使う
npm run sandbox -- --full    # カタカナ語や数値も ? で記録する
npm run sandbox -- --reset   # sandbox/ を作り直す
```

`sandbox/` が無ければここから複製し、`update` と `build` を流して結果を表にします。
`sandbox/` は git 管理外なので、自分のテキストを置いても構いません。
